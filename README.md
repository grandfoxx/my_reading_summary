# 내 독서 요약 (my_reading_summary)

BookOasis 용 개인 독서 통계 플러그인입니다. 로그인한 계정의 독서 기록으로 **월간 캘린더, 연간 통계, 연말 결산(리와인드)** 을 보여줍니다.

> A personal reading-stats plugin for BookOasis: monthly calendar, yearly statistics, and a year-in-review ("rewind") card, built from the reading log BookOasis already records.

현재 버전: **1.3.0** · 라이선스: [MIT](LICENSE)

> 이 프로젝트는 BookOasis 의 비공식 커뮤니티 플러그인이며 BookOasis 개발자와 관련이 없습니다.

## 기능

### 월간
- 이번 달 요약 카드: 독서 페이지, 독서 시간, 독서일수, 완독 권수
- 연속 독서일: 현재 연속 기록과 최장 기록, 각각의 기간(시작~끝)
- 최근 7일 현황
- 독서 달력: 읽은 분량을 5단계 색으로 표시, 완독한 날은 점과 표지 썸네일로 표시, 목표를 달성한 날은 초록 막대로 표시
- 날짜를 누르면 그날 읽은 책 목록(페이지·시간)과 완독 표시
- 카테고리(서재)별 누적 완독 권수
- **일간 목표**: 하루 목표를 페이지 또는 분으로 설정하고 오늘 진행률과 이번 달 달성 일수를 확인

### 연간
- 연도별 총 페이지, 총 시간, 독서일수, 완독 권수, 하루 평균, 읽는 속도(쪽/분), 최장 연속 독서
- 월별 독서량 차트, 요일별 독서량 차트
- 한 해 독서 달력(365일 잔디 형태)
- Top 5: 많이 읽은 책 / 시리즈 / 카테고리, 파일 형식별 집계
- 그 해에 완독한 책의 표지 모음
- **연간 목표**: 올해 완독 목표 권수와 진행률

### 리와인드
- 한 해를 요약한 카드(완독 권수, 읽은 시간·페이지, 가장 많이 읽은 달·요일, 최고의 하루, 많이 읽은 책 3권, 완독한 책 표지)
- **이미지(PNG)로 저장**, 텍스트 복사

### 내보내기
- 독서 기록 CSV (최근 2년의 날짜별 책 단위 기록, 엑셀에서 한글이 깨지지 않도록 BOM 포함)
- 선택한 연도의 요약 마크다운

### 서재 종류
- 일반 서재 / 성인 서재 / 오디오북 탭을 지원합니다.
- 오디오북은 일별 청취 기록이 없어서 완독 중심으로만 표시됩니다(페이지·시간·연속 기록 관련 항목은 숨김).

## 설치

BookOasis 가 설치된 폴더에서 플러그인 폴더를 만들고 파일을 넣습니다.

```bash
cd <BookOasis 폴더>/plugins/metadata
git clone https://github.com/grandfoxx/my_reading_summary.git
```

그다음 BookOasis 를 재시작합니다(플러그인 화면은 서버가 캐시하므로 재시작해야 반영됩니다).

```bash
docker restart bookoasis
```

관리자 설정의 플러그인 목록에서 **내 독서 요약** 을 켜면 사이드바에 같은 이름의 메뉴가 나타납니다. 사이드바 맨 아래쪽에 붙을 수 있으니 끝까지 스크롤해 보세요.

> 파일을 복사할 때 macOS 의 `tar` 로 보내면 `._*` 보조 파일이 같이 풀려서 플러그인 로드가 실패할 수 있습니다(`source code string cannot contain null bytes`). 이 경우 `ls -a` 로 `._` 로 시작하는 파일을 지우고 다시 재시작하세요.

## 업데이트

플러그인에 GitHub 업데이트 설정(`update_manifest`)이 들어 있어서, BookOasis 의 플러그인 업데이트 기능으로 이 저장소의 최신 파일을 받을 수 있습니다. 직접 받으려면 플러그인 폴더에서 `git pull` 을 한 뒤 BookOasis 를 재시작하세요.

## 필요한 데이터

BookOasis 가 이미 기록하는 아래 테이블을 읽기 전용으로 사용합니다. 별도의 테이블이나 설정을 만들지 않습니다.

| 테이블 | 용도 |
|---|---|
| `user_reading_log` | 날짜별·책별 읽은 페이지와 읽은 시간 |
| `user_progress` | 완독 여부와 완독일(마지막으로 읽은 날짜 기준) |
| `audiobook_progress` | 오디오북 완독 |
| `books`, `libraries` | 책 정보와 카테고리 이름 |

읽기 기록이 쌓여야 통계가 나옵니다. 기록은 BookOasis 뷰어가 책을 읽을 때 자동으로 남깁니다.

## 알아둘 점

- 기록은 **날짜 단위**로만 있어서 시간대별 통계는 제공하지 않습니다(요일별까지).
- 완독일은 별도 기록이 없어서 해당 책의 마지막 읽은 날짜를 사용합니다.
- 플러그인은 자체 서버 경로를 만들 수 없어서 모든 통계가 하나의 응답으로 전달됩니다. 기록이 많으면 응답이 수백 KB 가 될 수 있습니다. 날짜별 책 목록은 최근 2년으로 제한합니다.
- 일간·연간 목표는 **사용 중인 브라우저의 localStorage** 에 저장됩니다(기기·브라우저마다 따로). 서버에는 아무것도 저장하지 않습니다.
- 외부 서버로 데이터를 보내지 않습니다. 화면에 쓰는 아이콘은 BookOasis 에 포함된 Font Awesome 입니다.

## 삭제

플러그인 폴더를 지우고 BookOasis 를 재시작하세요. 브라우저에 저장된 목표 값(`mrs_*` 로 시작하는 localStorage 항목)은 남아 있어도 영향이 없습니다.
